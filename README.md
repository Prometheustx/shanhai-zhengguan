# 山海争关 · 双人塔防原型

双击 `index.html`，浏览器内直接试玩。入场前从八张角色卡里选择自己的守关人。单人对战中右关由 NPC 操作。手机横屏时，地图和商店并排。从四格商店把单位拖到空阵台部署，或拖到同种一级塔上直接合成。已有塔可拖到同种同级塔上合成，结果归拖动者。塔下方的小点表示等级。

首波准备最长 20 秒，也可以点击「就绪」提前开始。后续波次结束后休整 8 秒并自动开始下一波。看妖物身上的伤痕和步态可判断伤势。战场左上角可以暂停和切换一倍、二倍速，联机时该控制对双方生效。

点击波次标题可查看本波阵容。以原版同波妖物的生命为基准，回龙谷六波依次为 2.00、2.12、2.24、2.36、2.48、2.60 倍。山魈考验快速清怪，甲妖压迫持续火力，最后两波依次加入抗减速的蚀月妖将和会吞食回血的饕餮。

每人商店开局随机出现四件单位，双方的第一批相同。每格免费取用一次，刷新会替换全部货物。每人首刷花 8 灵气，此后每次增加 4 灵气。刷新次数按本局各自累计，跨波保留。下次刷新费用显示在商店按钮上。

两人分开玩：在本目录运行 `node server.js`，打开 `http://localhost:8787`，从「联机房间」创建或加入六位房间号。两台设备在同一局域网时，另一位用主机的局域网 IP 替换 `localhost`，端口仍是 8787。本原型独立运行，无 npm 依赖，不连接旧服。浏览器短时断线会重连，对局在两席重新在线前暂停；刷新页面不会恢复席位。

## 地图与竞争

**回龙谷**从北面的魔界裂隙通往南部人界防线。魔物先绕过北侧残阵，汇合后交错绕过谷中破损工事，再在南坡前汇合，最后沿河谷坡道分别走向两位守关人。

- 妖物出生时锁定绕行路线和目标关口，走北段左岔的妖物也能去右关。普通妖物在四条等长路径上均分，终波各关一只饕餮。
- 真人玩家可以使用全图 24 个阵位。单人模式的 NPC 只在右侧修饰阵台和夺阵，并根据通往右关的路程覆盖、现有火力与妖物威胁选择位置。塔当前归属以脚下的颜色为准。
- 范围内瞄准最接近终点的妖物。妖物被击败后释放灵气，归发出最后一击的一方。每波结束后，双方各获一份灵气补给。
- 同种同阶合成，原位置清空，目标格原地升一阶并归拖动方。例如把左关二阶逐日弓拖到右关二阶逐日弓上，右侧阵位变成左关的三阶逐日弓。商店卡片可直接与任意归属的同种一阶塔合成。
- 合成提升攻击力、射程或神农鼎的产气量，同时少占一个格。玩家要在当下的覆盖面积、下一次夺阵、释放阵位之间取舍。
- 一方先破关即败。打完六波先比关耐，再比击杀所得总灵气。双方同时破关或两项均相同则为平局。

## 六件灵器

| 灵器 | 打法与演出 |
| --- | --- |
| 东皇钟 | 攻速较慢，单体重击。钟身摆动，目标周围出现扩散的音震。 |
| 神农鼎 | 紫鼎在战斗中每 7 秒炼化灵气。一至三阶分别产出 2、3、5。紫气升起时显示入账数。 |
| 逐日弓 | 金弓从最远距离射击单只妖物。箭有金色弧形轨迹。 |
| 五雷令 | 蓝色令牌发出一道闪电。命中后雷纹扩散，范围内的妖物受伤并停步 0.85 秒。 |
| 火尖枪 | 红枪刺出火弧并在妖物身上留下持续 1.8 秒的灼烧。同一方再度命中会刷新灼烧，烧死妖物的灵气归施加方。 |
| 雷锤 | 雷公电母的雷锤近程落下，对周围造成溅射，带有金色震圈和地面裂纹。 |

佩戴型神器「神农鼎·鼎纹」仍为佩戴者提供击杀奖励。

## 角色和助阵

- 守关人有精卫、后羿、女娲、夸父、神农、大禹、雷公、常羲。入场前从全身角色卡选人。每人有一个主动技能，确认入场后不能更换，暂不设等阶。
- 第二波结束后，在布阵阶段可从十只灵兽中选一只。阵区型灵兽需要选一处阵位，其他灵兽直接助阵。
- 第二波结束后可用灵气购买六件神器中的一件。佩戴在塔上的神器可以免费换给己方塔。女娲石直接守护镇关。
- 最后一波两关各来一只饕餮。它低血时会停步蓄力，吞食附近同时攻向同一镇关的小妖并回血。
- 胜方守关人获得封印执掌权，结算会显示名字。平局由双关共同落印。

技能和效果全表见 [玩法与世界观草案](玩法与世界观草案.md)。地图和角色的美术约定见 [项目记忆](AGENTS.md)。本地历史样稿保存在「画风样稿」目录。

调数值和路线用 `rules.js`。`engine.js` 提供本地与房间共用的对局规则。运行 `node verify.js` 检查阵位和路径、合成、击杀归属、灵器机制与 NPC 的右关策略。

### 描边美术

回龙谷由斜俯视地表、沿路线绘制的道路和阵台，以及带细墨轮廓的独立地物组成。灰紫焦土经过残垣过渡到青绿河谷。妖物在灵器上层，脚下箭头标出目标关口。轻伤和重伤分别加深伤痕、降低饱和度，重伤时步态更沉。精卫和夸父同时重绘站姿和施法动作，分别体现小姑娘和魁梧汉子的比例。
