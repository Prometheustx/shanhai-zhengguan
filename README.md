# 山海争关 · 双人塔防原型

双击 `index.html`，浏览器内直接试玩。单人对战中选择自己的守关人后，右关由 NPC 操作。手机横屏时，地图和商店并排。从四格商店把单位拖到空阵台部署，或拖到同种一级塔上直接合成；已有塔可拖到同种同级塔上合成，结果归拖动者。塔下方的小点表示等级。

首波准备最长 20 秒，也可以点击「就绪」提前开始。后续波次结束后休整 8 秒并自动开始下一波。鬼怪越透明，剩余生命越少。

每人商店开局随机出现四件单位，双方的第一批相同。每格免费取用一次，刷新会替换全部货物。每人首刷花 8 灵气，此后每次增加 4 灵气。刷新次数按本局各自累计，跨波保留。下次刷新费用显示在商店按钮上。

两人分开玩：在本目录运行 `node server.js`，打开 `http://localhost:8787`，从「联机房间」创建或加入六位房间号。两台设备在同一局域网时，另一位用主机的局域网 IP 替换 `localhost`，端口仍是 8787。本原型独立运行，无 npm 依赖，不连接旧服。浏览器短时断线会重连，对局在两席重新在线前暂停；刷新页面不会恢复席位。

## 地图与竞争

**回龙谷**从北面的魔界裂隙通往南部人界防线。魔物越过焦土和破损的边境工事，在两条岔路绕过废墟，汇流后分别走向两位守关人所在的开放道路终点。

- 上段左右绕行和末端攻击对象是两件事。怪出生时锁定二者，走左岔的怪也能去右关。普通怪在四条等长路径上均分，终波各关一只饕餮。
- 全图 24 个阵位由双方共享，空位呈现为地面的残石基。前沿哨位能覆盖魔物刚越界的路段，汇流处适合争夺灵气，尾段适合留塔保关。每局随机镜像出怪顺序和同帧攻击先后。塔当前归属以颜色为准。
- 范围内瞄准最接近终点的妖物。妖物被击败后释放灵气，由击杀塔当前主人取得。每波结束后，双方各获一份灵气补给。
- 同种同阶合成，原位置清空，目标格原地升一阶并归拖动方。壹 + 壹 → 贰，贰 + 贰 → 叁。例如左关贰阶御剑徒拖到右关贰阶御剑徒上，右侧阵位变成左关的叁阶御剑徒。普通塔不能搬到空格，也不能用商店直接夺塔。
- 合成增加单塔攻击力和射程，同时少占一个格；叁阶只有一座塔在出手。玩家要在当下的覆盖面积、下一次夺阵、释放阵位之间取舍。
- 一方先破关即败。打完六波先比关耐，再比击杀所得总灵气。双方同时破关或两项均相同则为平局。

## 角色和助阵

- 入场前从十位守关人中选一位，每人有一个主动技能，确认进入后不能更换，暂不设等阶。
- 第二波结束后，在布阵阶段可从十只灵兽中选一只。阵区型灵兽需要选一处阵位，其他灵兽直接助阵。
- 第二波结束后可用灵气购买六件神器中的一件。佩戴在塔上的神器可以免费换给己方塔。女娲石直接守护镇关。
- 最后一波两关各来一只饕餮。它低血时会停步蓄力，吞食附近同时攻向同一镇关的小妖并回血。
- 胜方守关人获得封印执掌权，结算会显示名字。平局由双关共同落印。
