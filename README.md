# 山海争关 · 双人塔防原型

双击 `index.html`，浏览器内直接试玩，同屏用页面下方的「左关 / 右关」切换操作人。每位玩家选一个守关角色，在自己一侧的阵位召唤防守单位，两边都点「就绪」才放出妖潮。可以点击两座塔，或把自己的塔拖到另一座同种同阶塔上。

两人分开玩：在本目录运行 `node server.js`，打开 `http://localhost:8787`，从「联机房间」创建或加入六位房间号。两台设备在同一局域网时，另一位用主机的局域网 IP 替换 `localhost`，端口仍是 8787。本原型独立运行，无 npm 依赖，不连接旧服。浏览器短时断线会重连，对局在两席重新在线前暂停；刷新页面不会恢复席位。

## 地图与竞争

**回龙谷**从北面的魔界裂隙通往南部人界双关。魔物越过焦土和破损的边境工事，在两条岔路绕过废墟，汇流后分向人界左右镇关。

- 上段左右绕行和末端攻击对象是两件事。怪出生时锁定二者，走左岔的怪也能去右关。普通怪在四条等长路径上均分，终波各关一只饕餮。
- 两侧各有 12 个镜像阵位，全部位于人界。前沿哨位能覆盖魔物刚越界的路段，汇流处适合抢尾刀，尾段适合留塔保关。每局随机镜像出怪顺序和同帧攻击先后。塔当前归属以颜色为准。
- 范围内瞄准最接近终点的怪，不按归属挑怪。尾刀赏金全给击杀塔当前主人。过波保底发给两人各一份，给落后的一侧留翻盘机会。
- 同种同阶合成，原位置清空，目标格原地升一阶并归拖动方。壹 + 壹 → 贰，贰 + 贰 → 叁。例如左关贰阶御剑徒拖到右关贰阶御剑徒上，右侧阵位变成左关的叁阶御剑徒。普通塔不能搬到空格，也不能用商店直接夺塔。
- 合成增加单塔攻击力和射程，同时少占一个格；叁阶只有一座塔在出手。玩家要在当下的覆盖面积、下一次夺阵、释放阵位之间取舍。
- 一方先破关即败；同一刻双方破关为平局。打完六波先比关耐，再比尾刀总赏金，仍相同为平局。

## 角色和助阵

- 开局从十位守关人中选一位，每人有一个主动技能，暂不设等阶。
- 第二波结束后，在布阵阶段可从十只灵兽中选一只。阵区型灵兽需要点选一处本方阵位，其他灵兽直接助阵。
- 第二波结束后可用灵石购买六件神器中的一件。佩戴在塔上的神器可以免费换给己方塔。女娲石直接守护镇关。
- 最后一波两关各来一只饕餮。它低血时会停步蓄力，吞食附近同时攻向同一镇关的小妖并回血。
- 胜方守关人获得封印执掌权，结算会显示名字。平局由双关共同落印。
